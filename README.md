# 一周训练计划 · 动作要领

简约风格的健身教学静态页面：一周 5 练 2 休，每个动作写清组数、次数、组间休息、动作节奏、发力顺序和常见错误。界面按手机 App 的思路组织：底部四个栏目横向排列——周计划 / 热身拉伸 / 原则 / 计时打卡，点一下即切换。

## 打开方式

直接用浏览器打开 `index.html` 即可（手机浏览器也可以）。不需要服务器、不需要安装任何依赖，所有内容都在本地。

如果要让同一 Wi-Fi 下的手机访问，要用“绑定所有网卡”的方式启动（默认的 `python -m http.server` 只监听 127.0.0.1，手机连不上）：

```
python -m http.server 5173 --bind 0.0.0.0
```

再用 `ipconfig` 找到电脑的局域网 IPv4 地址，手机浏览器访问 `http://<电脑局域网 IP>:5173`。

几个常见坑：Windows 首次启动会弹防火墙提示，要选“允许访问”；手机必须连同一个 Wi-Fi（不是流量、也不是访客网络）；如果电脑和手机都连着同一个 Wi-Fi 却还是打不开，多半是路由器的「AP 隔离 / 客户端隔离」，换一个普通 Wi-Fi 再试。

另外：「我的相册」用的是浏览器本地数据库（IndexedDB），用 `file://` 双击打开时浏览器会禁止，页面会给出提示。想存照片就用本地服务器或线上网址打开。

改东西的时候更推荐用项目里的 `dev-server.py`：它跟上面的命令一样会绑定所有网卡，但额外关掉了浏览器缓存，改完文件点刷新就是最新的，不会出现“明明改了却还是旧的”。

```
python dev-server.py
```

## 目录结构

```
index.html                  页面骨架（顶栏 + 四个栏目：周计划 / 热身拉伸 / 原则 / 计时打卡，以及底部导航）
assets/css/style.css        全部样式（五套配色：白 / 黑 / 灰 / 粉 / 蓝，窄屏 / 宽屏自适应）
dev-server.py               本地预览服务器（关缓存，调试用，可以不上传）
assets/js/data/mon.js       各训练日的数据（周一胸 / 周二背 / 周三肩 / 周四腿 / 周五手臂核心 / 周六心肺 / 周日休息）
assets/js/data/*.js
assets/js/data/plan.js      周的汇总顺序，以及热身、拉伸、训练原则、顶部统计、激励语
assets/js/app.js            渲染与交互：切换栏目与训练日、配色与训练顺序、展开要领、图片放大、完成勾选、计时器、打卡
assets/img/                 动作示意图（mon-01…06 / tue-01…06 / wed-01…06 / leg-01…09 / arm-01…06，共 33 张）+ 主屏图标 icon-180 / 192 / 512.png
manifest.webmanifest        加到手机主屏时用的应用信息
sw.js                       离线缓存：首次打开把整站存到本机，之后断网也能开
preview/                    渲染预览图
```

## 怎么改

- 改某个动作的组数、次数、休息时间：打开对应星期的文件，例如 `assets/js/data/mon.js`，修改 `sets`、`reps`、`rest`、`tempo`。`rest` 写成 `"90 秒"` 这样的字符串，页面会自动用它生成“开始 90 秒间歇”按钮。
- 改动作要领：修改同一个动作里的 `cues`（要领，逐条显示）、`mistakes`（常见错误）、`tip`（提示）。
- 换动作：把整个动作对象替换掉即可，字段保持一致。
- 加一天或改星期：在 `assets/js/data/` 里新增或编辑文件，然后在 `index.html` 底部按顺序引入脚本，并在 `plan.js` 的 `PLAN` 数组里排好顺序。
- 改配色：五套配色都在 `assets/css/style.css` 顶部的 `html[data-theme="..."]` 区块里，改 `--accent`（强调色）、`--bg`（背景）、`--text`（正文色）即可。想加第六套，在 `app.js` 的 `THEMES` 里加一条，再补一个同名的 `html[data-theme="新名字"]` 区块。
- 改默认训练顺序：默认值在 `app.js` 的 `DEFAULT_SCHEDULE`（`mon tue wed thu fri sat sun` 依次对应周一到周日）；页面上改过的顺序存在 localStorage，优先级更高。
- 改栏目：四个栏目都是 `index.html` 里的 `<section class="tab-panel" data-tab="...">`，底部导航是 `#tabbar` 里的四个按钮；不要某个栏目，就把对应的 `<section>` 和导航按钮一起删掉。栏目名与别名在 `assets/js/app.js` 的 `TABS` 里。地址栏的 `#plan` / `#prep` / `#rules` / `#track` 可以直接跳到对应栏目。
- 改激励语：`assets/js/data/plan.js` 末尾的 `QUOTES` 数组，`en` 是英文原句、`zh` 是下面那行小字中文，每次打开随机取一条。

## 动作图怎么加、怎么换

图片放在 `assets/img/`，命名和动作顺序一一对应：

```
mon-01 … mon-06   周一 胸    6 个动作
tue-01 … tue-06   周二 背    6 个动作
wed-01 … wed-06   周三 肩    6 个动作
leg-01 … leg-09   周四 腿    9 个动作
arm-01 … arm-06   周五 手臂  6 个动作（当天的核心动作没有配图）
```

- 换图：直接用同名文件覆盖即可（建议 448×336、白底、JPEG）。
- 加图到其他训练日：把图片放进 `assets/img/`，再到对应日期的数据文件里给动作加一行 `img: "assets/img/xxx.jpg",`。
- 取消某个动作的图：删掉那一行 `img`。
- 折叠状态下的小缩略图和展开后的大图用的是同一张文件，不用分别准备。

现有的 33 张图是从五张训练计划拼图（周一胸 / 周二背 / 周三肩 / 臀腿 9 动作 / 手臂计划）里按坐标裁出来的：先定位每个动作的图形区，剔除图里的标题、图注文字和右下角水印，再统一排进 448×336 的白底画布。因此每张图都是纯动作示意，文字说明一律由页面自己渲染，改文案不用重新做图。

线上地址：<https://shiny-vacherin-2ad534.netlify.app/> ，代码仓库：<https://github.com/sherl786991-art/fitness-site> 。

改完东西要发布时，先在项目目录里跑两条命令，再部署：

```
node build-sw.js      # 重新生成离线缓存清单（改了网站文件就要跑）
node build-dist.js    # 生成 dist/：只含 index.html、manifest、sw.js、assets
netlify deploy --prod --dir=dist --site=9e50e535-2b53-4e20-91c6-a17d4a18afc5
```

`dist/` 是发布产物（已在 `.gitignore` 里），不要直接改它。也可以把 `dist/` 整个拖到 Netlify 的 Deploys 页面手动发布。

推送到 GitHub：

```
git add -A
git commit -m "说明"
git push
```

注意：这台机器上 git 需要走本地代理（仓库里已设 `http.proxy=http://127.0.0.1:7890`）；另外 C 盘上无法重命名文件（会报 `EXDEV`），所以 Netlify CLI 的配置目录被指到了 `D:\sherl\.netlify-cli-home`，运行时需要 `APPDATA` 指向它。

## 已实现的小功能

- 默认打开当天的训练（按系统时间判断星期）。
- 每个动作可展开查看详细要领；支持“展开全部 / 收起全部”。
- 五套配色（白 / 黑 / 灰 / 粉 / 蓝）：点左上角图标进“个人喜好”切换，选择存在本机；第一次打开默认跟随系统是浅色还是深色。
- 训练顺序可改：在“个人喜好”里，格子右边的小点可以拖动换顺序；点格子本身能把那天换成任意部位（比如周一不想练胸）。周计划、打卡统计会跟着变，还有“恢复默认顺序”一键还原。
- 周计划改成方格模块：7 天铺成方块，点哪块看哪天，方块上直接写着部位和完成进度。
- 勾选完成，进度条与方格上的圆点会更新，记录保存在浏览器 localStorage，可“重置勾选”。
- 组间休息计时器（在“计时打卡”栏目里）：30 / 45 / 60 / 90 / 120 秒预设，也可点动作卡片上的“开始 90 秒间歇”一键倒计时。倒计时中切到别的栏目会缩成底部一条继续跑；结束时响铃并震动（浏览器需先有过点击操作），标签页标题同步显示剩余时间。空格键可开始 / 暂停。
- 图片放大：点动作缩略图或展开后的示意图，全屏看细节，点任意处关闭。
- 我的相册（“计时打卡”栏目）：可以「拍一张」直接调起相机，也可以从相册里选（支持一次选多张）。照片会先在本地压到最长边 1600px 再存进浏览器的 IndexedDB，不上传、断网也能看；每张自动标注日期，点开可放大，右上角 × 删除，底部可「清空相册」。存照片时如果今天还没打卡，会顺手帮你打上。
- 离线可用：`manifest.webmanifest` + `sw.js` 会把整站缓存到本机，之后没网也能打开；手机浏览器菜单里选“添加到主屏幕”，点图标就像 App 一样打开。
- 打卡（“计时打卡”栏目）：练完点一下记一次，显示累计天数、连续天数、本周打卡次数和今天已完成 / 总动作数；今天还有动作没勾完会先提醒一句。记录同样存在 localStorage，换设备不会同步。
- 顶部标题栏跟着栏目切换，右侧显示当前训练日；今天还没打卡时，底部“计时打卡”图标上会有一个小圆点。

## 训练安排速览

| 星期 | 部位 | 时长 | 组间休息 |
| --- | --- | --- | --- |
| 周一 | 胸 | 约 65 分钟 | 60–90 秒 |
| 周二 | 背 | 约 65 分钟 | 60–90 秒 |
| 周三 | 肩 | 约 60 分钟 | 45–75 秒 |
| 周四 | 腿 | 约 75 分钟 | 45–120 秒 |
| 周五 | 手臂 · 核心 | 约 60 分钟 | 45–60 秒 |
| 周六 | 心肺 · 灵活性 | 约 45 分钟 | — |
| 周日 | 完全休息 | — | — |

周一至周三、周五各 6–8 个动作，周四腿日为 9 个动作；每个动作 3–4 组，复合动作组间 90–120 秒，孤立动作 45–60 秒。上面是默认安排，顺序可以在“个人喜好”里改成适合自己的。
